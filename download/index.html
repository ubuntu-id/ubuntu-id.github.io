Unduh Ubuntu

Anda dapat mengunduh versi terbaru Ubuntu dan menginstal serta menggunakannya di berbagai lingkungan.

Versi dan kebutuhan sistem

Ubuntu 26.04 LTS

Ubuntu 26.04 LTS, versi LTS (Long Term Support) terbaru, mendapat pemeliharaan dan pembaruan keamanan gratis selama 5 tahun. Untuk penggunaan yang stabil, versi LTS umumnya direkomendasikan.

Lihat catatan rilis Ubuntu 26.04 LTS

Ubuntu 26.10

Jika ingin mencoba fitur terbaru, coba Ubuntu 26.10, versi terbaru. Versi ini mendapat pemeliharaan dan pembaruan keamanan gratis selama 9 bulan.

Lihat catatan rilis Ubuntu 26.10

Siklus rilis dan dukungan Ubuntu

Versi baru Ubuntu dirilis setiap April dan Oktober, dengan jeda 6 bulan. Versi LTS baru dirilis setiap April tahun genap, dengan jeda 2 tahun. Pemeliharaan dan pembaruan keamanan gratis diberikan selama 5 tahun untuk versi LTS dan 9 bulan untuk rilis sementara. Informasi siklus rilis Ubuntu dapat dilihat di ubuntu.com.

Kebutuhan sistem

  • Prosesor dual core 2 GHz dan memori sistem 4 GB atau lebih baik
  • Ruang kosong hard disk 25 GB
  • Akses internet akan membantu
  • Drive DVD atau port USB untuk media instalasi

Jika memakai Windows 10 atau Windows 11 versi terbaru, Anda dapat mencoba Ubuntu dengan mudah lewat WSL.

Linux Containers

Image untuk Application Containers: untuk membangun image OCI yang dipakai dengan Docker, Podman, Kubernetes.

Image untuk System Containers (container bergaya VM): dipakai dengan LXD dan LXC sebagai pengganti beban kerja VM.

Dukungan teknis komersial

Catatan

Komunitas Ubuntu Indonesia adalah komunitas nirlaba yang terdiri dari pengguna dan pengembang, dan independen dari Canonical Ltd. Kami tidak menyediakan dukungan teknis komersial maupun jawaban atas pertanyaan terkait. Jika membutuhkan dukungan komersial untuk Ubuntu, lihat informasi di bawah dan dapatkan dukungan dari Canonical Ltd. atau mitra Canonical.

Ubuntu Advantage

Dapatkan dukungan teknis komersial dari Canonical Ltd., penerbit Ubuntu, lewat program Ubuntu Advantage. Paket yang tersedia adalah Essential (gratis), Standard (berbayar), dan Advanced (berbayar). Anda bisa mendapat dukungan untuk Desktop, Server, VM, dan aplikasi (mis. MySQL, MongoDB, NGINX, Kafka, dan lainnya).

Ubuntu Pro untuk cloud publik

Memakai AWS, Google Cloud, atau Microsoft Azure? Buat beban kerja VM dengan Ubuntu Pro, image Ubuntu premium dari Canonical Ltd., dan dapatkan dukungan teknis komersial tanpa kontrak tambahan.

Mitra Canonical

Mitra Canonical Ltd. juga menyediakan dukungan teknis komersial.
