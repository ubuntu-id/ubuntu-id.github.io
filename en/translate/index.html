Translate Ubuntu

Take part in translating the Ubuntu system UI and its bundled applications.

As an open source project, anyone can contribute to and improve the translation of the Ubuntu system UI and its bundled applications. Please join us in translating Ubuntu to make it easier for more users. Rather than translating a lot at once, it is better to translate a little accurately and consistently over time.

Take part in translating

You can take part by following the steps below.

  • Create a Launchpad account and log in
  • Find a package to translate
  • Write a translation and submit it as a suggestion
  • Ask for your suggestion to be reviewed, or wait for a review

Join the translation team

Only those who meet the requirements set out in the translation team’s rules can join the team and contribute further.
